# Sources of the import test files

Real public exports, cut to a few dozen rows, for the tests of `pivotkit-core/import`
(`test/import.test.js`). They are data, not code, and keep the licence of their source. Fetched on
2026-11-10; the terms below were read on that day.

| File | Source | Licence | What it tests |
| --- | --- | --- | --- |
| `kerg2-btw25.csv` | Die Bundeswahlleiterin, results of the German federal election 2025 by constituency (`kerg2.csv`, [open data](https://www.bundeswahlleiterin.de/bundestagswahlen/2025/ergebnisse/opendata.html)); the first 120 lines, unchanged | [Datenlizenz Deutschland – Namensnennung – Version 2.0](https://www.govdata.de/dl-de/by-2-0); attribution "(c) Die Bundeswahlleiterin, Wiesbaden 2025" (the file's first line) | UTF-8 with byte order mark, semicolons, a title block of nine lines, German numbers (`82,5122`) and dates (`23.02.2025`), area numbers with leading zeros (`01`) |
| `ladesaeulen-bnetza.csv` | Bundesnetzagentur, register of public charging points (Ladesäulenregister, list of 2026-09-01, [download page](https://www.bundesnetzagentur.de/DE/Fachthemen/ElektrizitaetundGas/E-Mobilitaet/start.html)); the title block, the header, the first 40 rows, 5 rows with line breaks inside quotes and 15 rows with a postcode starting with 0, each record unchanged | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); attribution "Bundesnetzagentur.de" | UTF-8 with byte order mark, CRLF, a title block of ten lines and a two-line header, semicolons inside quotes, line breaks inside quotes, German decimals (`48,442398`), postcodes with leading zeros |
| `ladesaeulen-bnetza-1252.csv` | the same excerpt, converted to Windows-1252 (as Excel saves "CSV" on a German Windows) | as above | Windows-1252 found after strict UTF-8 fails; the same table as the UTF-8 file |
| `usgs-earthquakes.csv` | U.S. Geological Survey, [earthquakes of magnitude 2.5 and more of the past week](https://earthquake.usgs.gov/earthquakes/feed/v1.0/csv.php) (2026-11-10), the first 60 rows | U.S. public domain; credit "U.S. Geological Survey" | commas, quoted values with commas, ISO date-times with an offset, English decimals |
| `usgs-earthquakes-utf16.txt` | the same rows, written as tab-separated UTF-16 little endian with a byte order mark and CRLF (Excel's "Unicode Text") | as above | UTF-16 with byte order mark, tabs |
| `nobel-laureates.json` | Nobel Prize Outreach, [api.nobelprize.org 2.1](https://www.nobelprize.org/about/developer-zone-2/) `laureates?limit=30&sort=asc`, the first 8 laureates of the response (meta and links unchanged) | [CC0](https://creativecommons.org/publicdomain/zero/1.0/); "Nobel Prize Outreach, api.nobelprize.org" | the rows under a property (`laureates`), nested objects, arrays, numbers as strings |
| `endoflife-nodejs.json` | [endoflife.date](https://endoflife.date/) API, `api/nodejs.json`, unchanged | [MIT](https://github.com/endoflife-date/endoflife.date/blob/master/LICENSE), "Copyright 2020 endoflife.date contributors" (licence text in `examples/playground/data/SOURCES.md`) | an array of objects; a column of dates and `false` mixed |

The Excel workbooks of pivotkit-xlsx's tests are generated by `packages/pivotkit-xlsx/test/make-xlsx.js`;
none is committed.
